AI 題庫整理 Prompt（雙 PDF 多年份通用）

單選題：提供 options（通常為 A, B, C, D，若有第五選項為 E），answer 為單一字串（如 "B"）。

[
  {
    "question": "下列關於抽胸水檢查的敘述何者正確？",
    "options": {
      "A": "Eosinophilia 代表乳糜胸",
      "B": "pH < 6.5，代表食道破裂"
    },
    "answer": "B",
    "explanation": "Esophageal rupture 通常伴隨胸水 pH 顯著降低。",
    "origin": "出自 B10 考古 第 3 題"
  }
]

多選題：提供 options，且 answer 為字串陣列（如 ["A", "C"]），陣列中每項都必須在 options 中。

[
  {
    "question": "下列關於心肌梗塞生化標記之敘述，何者正確？（多選）",
    "options": {
      "A": "Troponin I 特異性極高",
      "B": "CK-MB 上升速度最慢",
      "C": "Myoglobin 最早升高"
    },
    "answer": ["A", "C"],
    "explanation": "Troponin 為心肌特異標記；Myoglobin 於發作後 1-3 小時最早升高；CK-MB 於 4-6 小時升高。",
    "origin": "出自 B11 期末 第 15 題"
  }
]

是非題：options 欄位必須嚴格固定為 {"T": "True", "F": "False"}（若原卷為 (O)(X) 請統一轉換為 (T)(F)），answer 為單一字串 "T" 或 "F"。系統作答時會保持固定順序不隨機洗牌。

[
  {
    "question": "下列關於原發性肺結核病理變化的敘述是否正確？Ghon complex 包含肺部實質病灶與肺門淋巴結腫大。",
    "options": {
      "T": "True",
      "F": "False"
    },
    "answer": "T",
    "explanation": "原發性肺結核典型的 Ghon complex 即由 Ghon focus 加上同側肺門淋巴結病變所組成。",
    "origin": "出自 B11 考古 第 2 題"
  }
]

填空題 / 簡答題：絕對不可包含 options 欄位（省略 options）。answer 為字串陣列，列出所有可被接受的答案、同義詞或縮寫；若需修正詳解或補充，可於 explanation 內換行加上 **題矣註記：說明**。

[
  {
    "question": "在慢性骨髓性白血病（CML）中，常見由 t(9;22) 染色體易位形成的融合基因是 ______。",
    "answer": ["BCR-ABL", "BCR-ABL1", "BCR/ABL"],
    "explanation": "費城染色體造成 9 號染色體 ABL 與 22 號染色體 BCR 融合。\n\n**題矣註記：臨床首選標靶為酪胺酸激酶抑制劑（如 Imatinib）。**",
    "origin": "出自 110學年度 簡答題 第 1 題"
  }
]
命名格式
建議格式為 科目區段｜學年度 考卷名稱（例如：檢驗醫學區段一｜B10 考古、藥理區段一｜B11 期末）。
字元禁制
名稱絕對不可包含 . # $ [ ] /，亦不可使用 progress、mistakes 等保留名稱。
Markdown / LaTeX
題目及詳解支援 Markdown 排版（如 **粗體**、表格、清單）與 LaTeX 數學/化學公式（如 $E=mc^2$ 或 $\\text{pH} < 6.5$）。
