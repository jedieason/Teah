# 題矣：學習引擎與上線交接

本次不搬移 Gemini API 到後端，也沒有寫入正式 Firebase 或發佈網站。

## 交付內容

- 永久 questionId、revision、legacyIds、taxonomy、provenance；勘誤增加版本並保存原答案。
- IndexedDB 保存個人待送紀錄、讀過的題庫與續答快照；重新開頁後依登入帳戶恢復。作答使用穩定事件鍵，重送不增加次數。進度以 lastUpdated 避免舊離線快照覆蓋較新進度。
- learning/{uid}/attempts：題號、版本、測驗識別、原始選項答案、對錯、耗時、模式、AI／改選旗標、時間、來源與分類。舊資料不會被偽造成歷史事件。
- 自訂組題：題庫、科目、系統、主題、難度、年份、關鍵字、新題／最近錯題／到期／收藏、題數、優先弱項／隨機／原順序、獨立選項亂序、每題提醒。
- 學習模式逐題回饋；考試模式確認後鎖定答案，全部交卷才顯示回饋並記錄成績。這是自我練習模式，不是安全監考系統。未交卷的答案可續答。
- 學習總覽含近 7 天／前 7 天、平均作答秒數、分類表現、測驗與作答歷史、到期數量、讀書目標與每日建議。
- 題目複習使用簡單間隔倍增（1–90 天），錯誤回到一天；不是 FSRS 或經校準的能力模型。跨裝置事件按作答時間重算排程。
- 個人筆記、選取文字加入筆記、自建複習卡、翻面與自評排程。
- 內容工作台：草稿 → 送審 → 不同人核准 → 管理員發佈；來源、審核人、審核時間、發佈紀錄、舊版本建立回復草稿。
- 內容回報、管理員／審核者回覆、使用者查看解決結果。
- 使用者資料匯出、Google 重新驗證後刪除本服務帳戶、隱私與使用條款、預設關閉 Analytics。
- PWA manifest 與 Service Worker：快取已取得的程式和靜態資源；不快取 Firebase API、Gemini API 或匯出檔。初次使用仍需連線；離線只能使用此前載入的題庫與資源。
- 最近 100 筆本機診斷（錯誤類別／同步耗時／待送數），可匯出。不含題目、答案、金鑰、完整 URL。

## Firebase 與網站部署

1. 先備份現行 Firebase；確認匯出後是否已有新增資料。上傳 JSON 是使用者指定的後續操作，本次沒有代為上傳。
2. 匯入更新的 JSON，或對最新匯出重新執行遷移後匯入。
3. 發佈 `firebase/database.rules.example.json`。`firebase.json` 已指向這份規則，**只上傳 JSON 不會更新權限規則**。
4. 本輪按要求保留瀏覽器直呼 Gemini，因此 `/API_KEY` 僅允許已登入帳戶讀取、禁止用戶端寫入，維持既有 AI 功能可用。**這不是金鑰保護：任何獲准登入的使用者仍能取得金鑰。** 未新增伺服器配額、成本上限或濫用防護。未來完成代理後，請將這條 `.read` 改回 `false` 並輪替金鑰。
5. 維護者角色使用 Firebase Auth custom claims：`contributor`／`editor` 可建草稿；`reviewer` 可核准其他人的稿件；`admin` 可發佈及查看發佈紀錄。Claims 必須透過可信任管理環境設定，不能從網頁自授權；更新後需重新登入。舊版直接匯入、改名、典藏、勘誤為 admin 作業。
6. `npm run build` 產生 `dist/`，可沿用現有靜態網站部署方式。PWA 必須在 HTTPS 或 localhost 下使用。
7. 在 staging 與正式環境分別確認 Google authorized domains、兩個帳戶互不可讀、跨裝置同步、離線恢復、帳戶刪除與內容角色。模擬器通過不代表正式 rules 已部署。

## 測試

- `npm test`：純函式、題目標準化、事件去重／亂序、組題、統計、遷移冪等與備份保護、既有錯題與 AI review。
- `npm run check`、`npm run build`。
- 啟動 `npm run dev` 後，`npm run test:browser`、`npm run test:learning`、`npm run test:editorial`。測試會攔截 Firebase 並禁止正式後端請求。可用 CHROME_PATH 指定本機 Chrome。
- `npm run test:rules` 使用 demo-teah Database Emulator。最新版 Firebase CLI 需要 Java 21+；不使用正式 Firebase 專案。

## 界線與後續營運

本次的核心是個人學習產品。班級／作業／老師儀表板、付費訂閱／帳單／機構授權尚未實作；這些需要明確的營運需求與受信任後端。沒有新增假付款或僅由前端判定的付費權限。

遠端錯誤告警、伺服器配額與 AI 費用監控、推播排程尚未建置；目前診斷只在本機。Analytics 也不取代告警。

大量使用時，learning 的載入與帳戶內作答歷史仍需分頁；目前只適合既有規模的 beta。排程的個別題目事件索引與學習歷史都會隨作答增長。進度衝突使用裝置時間的 last-write-wins，並非協同合併；裝置時鐘偏差仍需處理。刪除帳戶不能遠端清除其他裝置的離線資料，需在各裝置清除網站資料。

題目 ID 必須保留到未來每次編修、重排或重新匯入；若匯入不含 ID 的整份新題庫，系統視為新題目。人工醫學 QA、來源版權確認與分類補註仍由內容維護者執行。
