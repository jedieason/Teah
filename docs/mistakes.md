# 錯題本規格

## 狀態

| 事件 | 錯誤次數 | 連續答對 | 狀態 |
| --- | --- | --- | --- |
| 第一次答錯 | 1 | 0 | 待複習 |
| 再次答錯 | +1 | 歸零 | 待複習 |
| 已有錯題紀錄，答對一次 | 不變 | +1 | 未滿 2 次保持待複習 |
| 連續答對兩次 | 不變 | +1 | 已熟悉 |
| 手動標為已熟悉 | 不變 | 不變 | 已熟悉 |
| 手動移回待複習 | 不變 | 歸零 | 待複習 |

這是清單整理規則，不是醫學能力或記憶保留率的判定。沒有預測分數、徽章或額外答題工具。

已熟悉的題目不刪除。典藏題庫的錯題也保留，可在錯題本複習。歷史紀錄沒有 `status` 時視為待複習。缺少舊作答答案時不臆測上次選項。

## 複習

「開始複習」使用目前搜尋、篩選及排序結果；有勾選時只練習所選題目。全選包含尚未展開載入的題目。清單每次顯示 30 題，避免大量題目與公式同時渲染。

練習開始時，每份來源題庫只讀取一次，優先使用題庫的現行答案與詳解；來源已移除或無法讀取時，使用錯題快照。快照無可核實的題目索引時，不能直接對來源勘誤。

單選、複選、填空沿用原答題介面。錯題複習與結果頁的「重做錯題」皆不覆寫原本整份測驗的進度。

## 儲存與相容

- 仍寫入 `mistakes/{uid}/{quizStorageKey}/{recordKey}`。
- 新題目使用題目文字與原始索引的 SHA-256，避免長題幹超過 Firebase key 長度限制。
- 舊 Base64 key 及曾因 `/` 分裂的巢狀 key 可讀取；找到既有紀錄時原地更新，不批次遷移。
- 選項洗牌後，儲存前轉回原題庫標籤，同時還原答案與上次作答。
- 每個作答以交易累計，保留最近 20 個事件 ID 供重試去重。本頁的失敗事件依原順序重試，不讓後續答對先越過失敗的答錯紀錄。
- 重試佇列是記憶體狀態。關閉或重新整理會失去未送出的資料，因此有未同步資料時會提示保留頁面。此版本不宣稱離線持久化。
- 改題幹或調整題目順序仍可能形成新的識別；將來題庫格式應加入不變的 `questionId` 再安排一次遷移。

## 已驗證

單元測試涵蓋狀態轉換、重試去重、舊 key、洗牌答案還原、題型正規化、篩選及匯入格式。瀏覽器測試使用隔離資料驗證手機與桌面清單、狀態往返、跨題庫作答、重複確認及續答。
