# AI 觀念字卡

## 使用方式

1. 打開錯題本，選擇科目／題庫或勾選錯題，再按「AI 一鍵製作字卡」。只使用待複習題目；已熟悉題目不納入。未勾選時依目前排序取前 30 題，超過時按鈕明確顯示「前 30 題」；手動選取每次最多 30 題。
2. AI 整合不熟的共同觀念，產生回想問題、短答案、補充說明、填空提示、同義詞與來源錯題。自動保存為一組字卡；可以直接練習，也可以逐卡編輯或刪除。
3. 「字卡」模式按空白鍵或點「查看答案」翻面，再選「還不熟／記得了」。空白鍵不攔截文字輸入、其他按鈕與中文選字。
4. 「Learn」模式輸入填空答案，按 Enter 確認。答錯時呈現答案與說明，可自行標為正確；本輪完成可重練不熟的卡片。自行標記不會默默新增同義詞，要長期接受其他答案請編輯字卡。
5. 首頁「複習卡」可再次開啟全部字卡集、建立自己的卡片、編輯、選擇到期卡片或重練整組。

輸入比對採明確答案清單，忽略全半形、大小寫及多餘空白，但保留數值與符號。不是 AI 語意評分，不會把否定詞或不相等的醫學數值模糊判對。編輯時需同時核對背面答案、填空提示與同義詞。

## 儲存與相容性

字卡集存於既有 `learning/{uid}/deck_{uuid}`，內含 `title`、`cards`、`sources`、`aiGenerated`、時間與個別卡片的間隔排程。使用現有 IndexedDB outbox 與帳戶專屬 Firebase 規則，不需要再遷移題庫 JSON 或改動規則。

舊 `card_...` 筆記字卡仍可開啟、翻面及編輯；首次使用打字練習前需補上填空與可接受答案。字卡的複習結果不修改原題目的錯題次數或能力統計。匯出與刪除帳戶包含所有字卡集。

## AI 與介面

沿用目前登入後取得 Gemini key 的前端呼叫方式。請求包含所選錯題的內容、答案、詳解與上次作答；不傳其他學習歷史。AI 回應需通過來源 ID、字數、答案、單一空格與重複檢查才保存。關閉中止生成；失敗有重試，逾時 90 秒。AI 內容仍需人工核對，不代表醫學 QA。

新介面沿用題矣的字體、配色、按鈕、留白與答題進度樣式，支援手機、深色模式、鍵盤、Markdown 與 LaTeX。原生 dialog 的鍵盤不會觸發底下的測驗快捷鍵。

## 驗證

`npm test` 包含答案比對、來源驗證、字卡 schema 與排程測試。

啟動 `npm run dev` 後跑 `npm run test:flashcards`，可設定 `CHROME_PATH`。瀏覽器測試以假 Firebase 和假 AI 回應涵蓋錯題來源、失敗重試、編輯／重載、空白鍵、打字、同義詞、錯卡重練、手機／深色模式及取消；不會耗用真實 AI 額度。
